# Security

Tsenta hosts the MCP server described in this repository. To report a vulnerability in the server, its sign-in flow or any Tsenta service, follow the [Tsenta bug bounty](https://tsenta.com/bug-bounty) page, or email [founders@tsenta.com](mailto:founders@tsenta.com) with "Security" in the subject.

Please don't open a public issue for a security problem. Include the steps to reproduce it, what you expected and what happened. Don't access or change other people's data while testing.

If you think someone else's app is impersonating Tsenta on the approval screen, email the same address with the client name the screen showed.
